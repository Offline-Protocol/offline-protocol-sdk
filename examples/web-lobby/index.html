Pong Lobby

Each browser runs a full Offline Protocol node in a Web Worker. The host makes an MLS group, every device that connects is invited, and the game state travels end-to-end encrypted through the group, ten times a second, with no server. Devices connect over WebRTC on the local network with two codes; tabs of one browser find each other on their own.
