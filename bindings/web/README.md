# @offlineprotocol/web

WebAssembly bindings for the Offline Protocol SDK - enabling offline-first messaging in web browsers.

## Features

- 🌐 **Browser Support**: Runs in any modern web browser
- ⚡ **High Performance**: WebAssembly performance (near-native speed)
- 🔐 **Memory Safe**: Rust-powered with zero memory vulnerabilities
- 📡 **Internet Transport**: Uses Internet connectivity (BLE/WiFi unavailable in browsers)

## Installation

```bash
npm install @offlineprotocol/web
# or
yarn add @offlineprotocol/web
```

## Usage

### Basic Setup

```javascript
import init, { OfflineProtocol, MessagePriority } from '@offlineprotocol/web';

// Initialize WASM module
await init();

// Create protocol instance
const config = {
  appId: 'my-web-app',
  userId: 'user123',
  transport: {
    bleEnabled: false,        // Not available in browsers
    wifiDirectEnabled: false, // Not available in browsers
    internetEnabled: true,    // Only Internet works
  }
};

const protocol = new OfflineProtocol(JSON.stringify(config));

// Start protocol
await protocol.start();
```

### Sending Messages

```javascript
// Send a message
const messageId = await protocol.sendMessage(
  'user456',                  // recipient
  'Hello from the web!',      // content
  MessagePriority.Medium      // priority
);

console.log('Message sent:', messageId);
```

### TypeScript Support

The package includes TypeScript definitions generated by wasm-bindgen.

```typescript
import init, { OfflineProtocol, MessagePriority } from '@offlineprotocol/web';

await init();

const protocol = new OfflineProtocol(JSON.stringify({
  appId: 'my-app',
  userId: 'user123',
}));

await protocol.start();

const messageId: string = await protocol.sendMessage(
  'recipient',
  'content',
  MessagePriority.High
);
```

## Building from Source

```bash
# Install wasm-pack
curl https://rustwasm.github.io/wasm-pack/installer/init.sh -sSf | sh

# Build for web
wasm-pack build --target web --out-dir pkg

# Build for Node.js
wasm-pack build --target nodejs --out-dir pkg-node
```

## Browser Compatibility

- Chrome/Edge: ✅ Full support
- Firefox: ✅ Full support
- Safari: ✅ Full support
- IE: ❌ Not supported (no WebAssembly)

## Limitations

Unlike the native mobile SDKs, the web version:
- ❌ No BLE Mesh support (browser limitation)
- ❌ No Wi-Fi Direct support (browser limitation)
- ✅ Internet transport only
- ℹ️ Future: Web Bluetooth API could enable limited BLE support

## Performance

WebAssembly provides near-native performance:
- ~5-10x faster than pure JavaScript
- Small bundle size (~200KB gzipped)
- Fast startup time
